## Oracle — September

- **Process:** OA (DSA + SQL + aptitude) → Tech round (DSA, OOP, DBMS) → Managerial (system design lite + behavioural).
- **DSA weighting:** Arrays, Strings, Trees, Hash Maps, medium DP. Graphs appear but less than at Flipkart.
- **The separate gate:** SQL. Joins, group-by/having, subqueries, window functions. No amount of pattern repair helps here — carve a dedicated block.
- **They love DBMS depth:** normalisation to BCNF, ACID, isolation levels, indexing, B+ trees, query optimisation. Read about why a B+ tree beats a B-tree for range scans.
- **Java specifics:** collections and their complexities, HashMap internals, multithreading basics, JVM memory model.

## VISA — September

- **Process:** OA (2 DSA problems) → Tech 1 (DSA + Java/Spring depth) → Tech 2 (system design lite + projects) → HR.
- **DSA weighting:** Arrays, Strings, Trees, Graphs, medium DP. Solve in Java specifically.
- **Java concurrency:** synchronized vs volatile, ConcurrentHashMap, thread pools, the difference between a race condition and a deadlock.
- **The project round is decisive:** REST API design principles, JWT flow, layered architecture, why DTOs. This is where a defendable deployed project changes the outcome.

## SAP Labs — September

- **Process:** OA (DSA + aptitude) → Tech 1 (DSA + Java fundamentals) → Tech 2 (project deep dive + situational) → Managerial.
- **DSA weighting:** Arrays, Strings, Trees, Recursion. Slightly gentler than VISA.
- **The project round is heavy:** expect to whiteboard your architecture and defend every design decision. Prepare the 30-second, 3-minute and 15-minute versions.

## IBM — September and December

- **Process:** OA → Tech rounds → HM. Multiple tracks.
- **Weighting:** broad medium band. The December Data Scientist track is where your DA-ZVAD thesis becomes the strongest asset you have.

## Flipkart — August wave

- **Process:** OA (2–3 medium-hard) → ML round → Tech 1 & 2 → HM.
- **Weighting:** Arrays, Trees, Graphs, DP — the heaviest graph and DP load of any target on your list.
- **Also:** system design basics (URL shortener, rate limiter) and STAR behavioural stories.
