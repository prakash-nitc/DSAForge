Nineteen cards. Each is a self-contained 90-minute repair session (§5): template, knobs, triggers, three anchors, your own problems mapped to templates, decay signatures, Java traps, complexity, and the follow-ups an interviewer will actually ask.

> [!NOTE]
> **How to run a card**
>
> Open it. Cover the template — hand, or scroll past. Write it from memory on paper. Then uncover and fix only the differences. Then run the three anchors cold with a visible timer. Then log. Ninety minutes, close the card.
>
> Do not read three cards in a sitting. That is studying about studying, which is the exact failure mode this document exists to break.
