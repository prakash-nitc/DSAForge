> [!NOTE]
> **This document has one job**
>
> You have 111 problems in the ground. Roughly nine of them survive a cold re-solve. Everything in these pages exists to close that gap — not by adding problems, but by changing what you do with the ones you have.
>
> Read Part 0. Run one card. Report the number.

This is a reference, not a book. Nobody reads it front to back and nobody should. It has five entry points; go to yours and start today.

## The five entry points

| If you are… | Go to | What happens |
| --- | --- | --- |
| …about to sit an OA in 24–72 hours | §7.1 / §7.2 — Emergency protocols | Reactivation only. No new topics. |
| …doing your normal daily prep | §7.7 — The 25-Minute Daily Loop | Permanent standing routine, non-negotiable |
| …repairing a pattern that has decayed | Part II — the relevant card | One 90-minute session restores 6–20 problems |
| …building a topic from zero (Graphs, DP, Tries) | Part III — Topic Builds | Templates first, then problems, 4–6 days each |
| …blanking on Java syntax under pressure | Part IV — Java Combat Reference | Collections, idioms, traps, complexity |
| …the night before an interview | Appendix J + Appendix A | Checklist + the complete template library |

## The full map

| Part | Contents | Use it when |
| --- | --- | --- |
| Part I — The System (§1–§10) | Audit, diagnosis, mastery ladder, the science, the 90-minute repair engine, seven playbooks, retention machinery, the identification drill, the stuck protocol, OA/interview execution | Once, now. Then reference §7 and §8 constantly. |
| Part II — The Pattern Library (19 cards) | Every pattern: templates with variants, the knobs, triggers, anchors, decay signatures, complete problem map, Java bugs, complexity, interview follow-ups | One card per repair session, forever |
| Part III — Topic Builds | Trees (5 shapes, 31 problems), Graphs (8 templates, 20 problems), DP (8 templates, the ladder method), Tries, Bit Manipulation, Union-Find, Greedy | When a topic is at or near zero |
| Part IV — Java Combat Reference | Collections + complexity, the 30 idioms, the 18 traps, fast I/O, what interviewers notice | Whenever syntax slows you down |
| Appendices A–K | Complete template library, complexity master table, 39-anchor tracker, full 176-problem index, decision tree, edge-case checklist, company banks, 4-week calendar, spaced-repetition log, night-before checklist, the rules | Print A, C, and K. Reference the rest. |

> [!TIP]
> **Three things to print**
>
> Appendix A — The Complete Template Library. This is the one you blank-page from.
>
> Appendix C — The 39 Anchor Problems, with date boxes. This is the one you tick.
>
> Appendix K — The Rules. This is the one you tape above your desk.

> [!WARNING]
> **And one warning**
>
> Reading this document is not preparation. Running a session from it is. The measure of whether it worked is whether you complete one Part II card within twenty-four hours of opening it. If a week passes and you have read fifty pages and repaired zero patterns, this document has become the problem it was written to solve.
